# Política de Seguridad

Nos tomamos muy en serio la seguridad y la privacidad de **Floating Personal Gantt**.

---

## 🔒 Versiones Soportadas

Actualmente se proporciona soporte de seguridad y parches para la versión más reciente en la rama `main`:

| Versión | Soportada |
| :--- | :--- |
| `0.1.x` (Latest) | ✅ Sí |
| `< 0.1.0` | ❌ No |

---

## 🛡️ Reporte de Vulnerabilidades

Si descubres una posible vulnerabilidad de seguridad en esta aplicación:

1. **NO abras un Issue público en GitHub**.
2. Envía un reporte detallado a través de **GitHub Security Advisories** en la pestaña de Seguridad del repositorio o contacta de manera privada a los mantenedores.
3. Incluye:
   - Descripción detallada de la vulnerabilidad.
   - Pasos precisos para reproducir el comportamiento.
   - Impacto potencial estimado.

Agradecemos tu colaboración responsable para mantener este proyecto seguro.
